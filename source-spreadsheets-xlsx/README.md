# Source spreadsheets — XLSX copies

Contains 621 XLSX workbooks: 311 converted from XLS with Microsoft Excel, plus 310 existing XLSX workbooks copied byte-for-byte. The source ZIP is unchanged.

VBA projects were removed from 27 converted workbooks with user approval. Macros were not executed and external links were not updated.

All converted workbooks passed the checks described in conversion-manifest.json. That manifest and conversion-map.csv map original files to the new files and SHA-256 digests. Filename hash prefixes identify the ORIGINAL source bytes, not the converted XLSX bytes.

Original metadata, attribution/NOTICE, database references, manifest and old checksums are retained in original-package-metadata/ for provenance only. They describe the original source package and have not been rewritten to claim these conversions are publisher originals. New CHECKSUMS.sha256 covers this package.
